# Approved Native Direction

Approved: 2026-11-03. The owner approved .impeccable/mocks/04-neon-four-screens.png, prioritizing lightweight effects and performance.

## Contract

- Native Compose/Material 3, Persian RTL and English LTR.
- Near-black background, cyan primary actions, violet selected navigation, readable white text and muted blue-gray secondary text.
- One bounded luminous circular Telegram action on Home, an evidence-based benchmark gauge, outlined repeated proxy items and grouped settings.
- Native controls and semantic text, not screenshots used as an interface. No web animation runtime or 3D scene.
- Preserve separate testing/open-in-Telegram actions, every existing feature route, actual backend status, cancellation and current-network evidence.
- The reference's check icons and mock values are not literal state logic. Unmeasured throughput remains unknown. No VPN-connected claim.
- Reserve stable layout dimensions, respect font scaling and system animation scale. Gradients are confined to the approved ring and active accents.
- A compact layout must retain useful list space; expanded details and advanced controls must not overwhelm the default view.

## Palette

Dark background #080D1B, surface #111B30, primary cyan #22D9E8, secondary violet #A58AFF, readable foreground #F3F6FF, muted foreground #B2BDD1. Confirmation and failure use separate semantic roles plus text.

## First-Viewport Regions

Home: app bar, bounded Telegram action, current selected endpoint/evidence, compact sorting and paged results, bottom navigation. Testing: count, evidence gauge/stage progress, start/pause/cancel, optional transfer and real results. Library: native categories, distinct protocol panels. Settings: grouped native controls, account, channel and attribution.
