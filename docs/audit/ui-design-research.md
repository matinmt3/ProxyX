## Applied direction

Retain Material 3, existing colors, Persian RTL and English. Generic HTTP/SOCKS gets its own Vault tab, paged list, protocol menu, host search, per-row tests, batch count, progress/cancel and source-health dialog. Rows show real status and measurement time; source country is explicitly labeled and other-network results do not appear as current successes. No fabricated speed or Telegram-connect action is present.

Dashboard layout uses actual constrained space rather than physical screen height. Benchmark completion refreshes the paging generation once; later unrelated database invalidations should not keep resetting the scroll position. Screenshots/device observations are recorded separately in final-verification.md.
