# سورس ProxyX 8.0.0 Preview

این بسته شامل کد Kotlin و Java، رابط بازطراحی‌شدهٔ Compose، منابع برنامه، تست‌ها، اسکیماهای Room، ماژول Baseline Profile، Gradle Wrapper، کتابخانه‌های بومی TDLib برای سه معماری و مجوزهای WEB و قلم فارسی است. کد اجرایی با APK پیش‌نمایش 8.0.0 متناظر است. این نسخه Debug است و آمادهٔ انتشار عمومی محسوب نمی‌شود؛ تأیید نهایی ظاهر و عملکرد دستگاه به‌علت ناپایداری شبیه‌ساز کامل نشده است.

## ساخت

1. ZIP را در یک پوشهٔ جدا استخراج و همان پوشه را در Android Studio باز کنید.
2. JDK 21 و Android SDK موردنیاز تنظیمات Gradle را نصب کنید. دریافت وابستگی‌ها در اولین Sync به اینترنت نیاز دارد.
3. Android Studio مسیر SDK را در `local.properties` تنظیم می‌کند. برای قابلیت ورود تلگرام، مقادیر `telegram.apiId` و `telegram.apiHash` متعلق به خودتان را در همین فایل وارد کنید؛ قالب بدون اطلاعات محرمانه در `local.properties.example` موجود است.
4. برای ساخت نسخهٔ تست، `gradlew.bat :app:assembleDebug` را اجرا کنید. خروجی در `app/build/outputs/apk/debug` قرار می‌گیرد.

اجرای تست‌ها و ساخت Release:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintRelease :app:assembleRelease --no-daemon --max-workers=1
```

برای امضای Release، تنظیمات معتبر `storeFile`، `storePassword`، `keyAlias` و `keyPassword` را در `keystore.properties` قرار دهید یا متغیرهای محیطی معرفی‌شده در README را تنظیم کنید. بدون آن‌ها خروجی Release امضای انتشار ندارد.

## اطلاعات خصوصی

فایل‌های واقعی `local.properties` و `keystore.properties`، کلید امضا، نشست تلگرام، کش Gradle، خروجی بیلد، APKهای قدیمی و لاگ‌های دستگاه در ZIP قرار نگرفته‌اند. فایل‌های خصوصی موجود در پروژهٔ اصلی لپ‌تاپ حذف یا تغییر داده نشده‌اند.

برای انتشار آپدیت قابل نصب روی APK قبلی، همان کلید امضای اصلی لازم است. نسخهٔ Debug معمولاً نمی‌تواند جایگزین APK امضاشدهٔ Release شود؛ برای آزمایش Debug از دستگاه یا شبیه‌ساز جدا استفاده کنید و برای رفع خطای امضا، نسخهٔ دارای نشست تلگرام را حذف نکنید.

## تأیید بسته

فهرست SHA-256 فایل‌های داخل بسته در `SOURCE-MANIFEST.sha256` قرار دارد. هنگام بسته‌بندی، محتوای فایل‌های ZIP با فایل‌های منبع مقایسه می‌شود. این بررسی صحت بسته‌بندی است، نه یک بیلد مجدد از ZIP استخراج‌شده. نتیجهٔ تست‌های این نسخه و محدودیت‌های باقی‌مانده در [گزارش پیش‌نمایش](NEON-VERIFICATION.md) و [بازبینی نهایی](NEON-FINISH-REVIEW.md) آمده است؛ گزارش‌های 7.1.0 صرفاً سابقهٔ نسخهٔ قبلی هستند. APK را همراه سورس متناظر و مجوز GPL-2.0 تحویل دهید.
