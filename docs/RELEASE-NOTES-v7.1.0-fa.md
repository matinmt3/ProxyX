# ProxyX 7.1.0

## وب‌پروکسی تلگرام

- بخش جدید: گنجینه > WEB.
- افزودن لینک‌های `tg://webproxy` و `https://t.me/webproxy`، از جمله لینک‌های دارای مسیر و Secret علامت‌گذاری‌شده.
- دریافت از سه فید عمومی تلگرام. اگر فیدها در دسترس نباشند، فقط در فهرست عمومی خالی، هفت لینک اولیهٔ عمومی با برچسب تست‌نشده اضافه می‌شوند. این لینک‌ها تضمین اتصال یا تأیید اعتماد نیستند.
- تست سه‌مرحله‌ای واقعی: بررسی DNS و نشانی عمومی، نشست احراز‌شدهٔ WEB و سه پاسخ واقعی MTProto از مسیر تلگرام.
- مرحلهٔ چهارم اختیاری: سه دور آپلود و دانلود فایل تصادفی در Saved Messages با TDLib و بررسی صحت فایل. مصرف داده حدود ۹ مگابایت به‌علاوهٔ سربار شبکه است.
- سرعت دانلود و آپلود فقط بعد از تکمیل انتقال واقعی و برای همان شبکه نمایش داده می‌شود. تأیید پروتکل به‌تنهایی سرعت فایل محسوب نمی‌شود.
- بازکردن لینک در تلگرام از تست داخل برنامه جداست و به کلاینت تلگرامِ سازگار با WEB نیاز دارد.

## اصلاحات

- پردازش لینک‌ها در پس‌زمینه انجام می‌شود و پس از افزودن یا دریافت، ابتدای فهرست WEB نمایش داده می‌شود.
- پینگ و سرعتِ شبکهٔ قبلی بر رتبه‌بندی WEB در شبکهٔ جدید اثر ندارند.
- نبود اینترنت، تغییر شبکه، مشکل DNS و محدودیت اینترنت نامحدود از شکست پروکسی تفکیک می‌شوند.
- لغو یا خروج از صفحهٔ WEB، پل محلی و منابع تست را می‌بندد. دریافت منابع و DNS زمان و تعداد پردازش‌گر محدود دارند.
- صفحهٔ ارائه‌دهنده فقط پس از تأیید اعتماد، در WebView محدودشده اجرا می‌شود. دسترسی فایل و محتوا، مجوزهای دستگاه، پنجره‌های جدید و درخواست‌های خارج از مسیر مجاز مسدودند؛ خطای SSL نادیده گرفته نمی‌شود.
- فریم‌های بزرگِ معتبر WEB پیش از ورود به پل اندروید قطعه‌بندی می‌شوند تا انتقال فایل با محدودیت IPC سازگار باشد؛ دادهٔ رمز‌شده تغییر نمی‌کند.
- متن تأیید اعتماد و هشدار مصرف دیتا در صفحهٔ افقی و فونت بزرگ قابل اسکرول است؛ دکمهٔ لغو تست هنگام اسکرول فهرست در دسترس می‌ماند.
- نوار تب‌های گنجینه در فونت بزرگ اسکرول‌پذیر است تا عنوان‌ها بریده نشوند.
- نمایش عددی پینگ، سرعت و واحدها در رابط فارسی چپ‌به‌راست است؛ تعداد دورهای تأییدشده جدا نمایش داده می‌شود تا نتیجه به‌هم نریزد.
- مهاجرت دیتابیس، داده‌های موجود و نشست ذخیره‌شدهٔ تلگرام را حفظ می‌کند.

## استفاده

1. وارد گنجینه و سپس WEB شوید؛ لینک خود را اضافه کنید یا دکمهٔ دریافت را بزنید.
2. برای هر ارائه‌دهندهٔ مورد اعتماد، دکمهٔ تست را بزنید. WebView سازگار و به‌روز لازم است.
3. برای اندازه‌گیری سرعت واقعی فایل، ابتدا در تنظیمات وارد تلگرام شوید و گزینهٔ انتقال واقعی فایل را در WEB روشن کنید.
4. دکمهٔ تلگرام فقط لینک را به کلاینت بیرونی می‌فرستد؛ موفقیت تست داخل برنامه تضمین سازگاری آن کلاینت یا اتصال همیشگی نیست.

WEB جدا از فهرست و بنچ‌مارک گروهی MTProto نگهداری می‌شود و تست آن در این نسخه، تک‌پروکسی و فقط در پیش‌زمینه است. نتیجهٔ شبیه‌ساز یا وای‌فای، تضمین نتیجه روی اینترنت سیم‌کارت نیست.

بخش انتقال WEB از کد GPL-2.0 تلگرام اقتباس شده است؛ APK را همراه سورس متناظر و فایل‌های مجوز تحویل دهید. برای وضعیت دقیق آزمون‌ها، گزارش QA همراه بسته را بخوانید.
