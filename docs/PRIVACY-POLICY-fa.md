# سیاست حریم خصوصی ProxyX

آخرین به‌روزرسانی: 2026-10-06

ProxyX هیچ سرویس تبلیغاتی یا تحلیل رفتار کاربر ندارد و اطلاعات شخصی را برای سازنده ارسال نمی‌کند.

## داده و شبکه

- برنامه برای دریافت فهرست‌های عمومی MTProto و انجام آزمون‌های شبکه از اتصال اینترنت فعال دستگاه استفاده می‌کند.
- نتیجه‌های تست، علاقه‌مندی‌ها، تنظیمات و سابقهٔ کیفیت به‌صورت محلی روی دستگاه ذخیره می‌شوند.
- شناسهٔ شبکه یک اثرانگشت هش‌شده برای تشخیص تغییر مسیر است؛ نام Wi-Fi یا شناسهٔ خام شبکه در گزارش عیب‌یابی صادر نمی‌شود.
- تست سرعت مستقیم و انتقال واقعی TDLib مصرف اینترنت دارند. برنامه پیش از بنچ‌مارک، برآورد مصرف را نمایش می‌دهد و گزینهٔ محدودیت دیتا ارائه می‌کند.

## تلگرام و TDLib

- ورود به TDLib کاملاً اختیاری است.
- فایل‌های نشست و کلید دیتابیس TDLib در فضای خصوصی و خارج از Android Backup نگهداری می‌شوند.
- با قلب‌کردن یک پروکسی، فقط لینک اتصال و نتیجه‌های همان پروکسی به Saved Messages حساب خود کاربر ارسال می‌شود.
- شماره تلفن، کد ورود، رمز دومرحله‌ای، کلید نشست، Secret پروکسی و محتوای پیام‌ها برای سازنده ارسال نمی‌شوند.

## ارائه‌دهندگان WEB

- واردکردن لینک WEB کد ارائه‌دهنده را اجرا نمی‌کند. تست فقط پس از تأیید اعتماد و هنگام بازبودن صفحهٔ WEB اجرا می‌شود.
- صفحه در WebView محدودشده اجرا می‌شود و به نشست TDLib، فایل‌های خصوصی برنامه، کلیپ‌بورد یا مجوزهای دستگاه دسترسی ندارد. خطای SSL نادیده گرفته نمی‌شود.
- ارائه‌دهنده می‌تواند IP کاربر، درخواست پل احراز‌شده و حجم و زمان‌بندی ترافیک رمز‌شده را ببیند. ثبت اطلاعات در سرور آن مستقل از ProxyX است؛ حضور در فهرست عمومی به معنی تأیید اعتماد نیست.
- تست اختیاری فایل WEB سه فایل تصادفی را در Saved Messages خود کاربر آپلود و دانلود می‌کند؛ حدود ۹ مگابایت داده به‌علاوهٔ سربار شبکه. پیام‌های آزمایشی ممکن است باقی بمانند و هیچ پیام نامرتبطی حذف نمی‌شود.
- سرعت واقعی WEB فقط پس از تکمیل انتقال تلگرام و برای همان شبکهٔ فعال نمایش داده می‌شود.

## حذف داده

کاربر می‌تواند داده‌های پروکسی را از بخش Settings پاک کند و با خروج از حالت Telegram Transfer نشست TDLib را حذف کند. حذف خود برنامه نیز داده‌های خصوصی محلی آن را پاک می‌کند.
