# Bundled Typeface

Vazirmatn v33.003 by The Vazirmatn Project Authors.

Official repository: https://github.com/rastikerdar/vazirmatn

Unmodified static Regular and Bold TTF files were downloaded from the pinned v33.003 tag. The SIL Open Font License 1.1 is bundled at app/src/main/assets/licenses/Vazirmatn-OFL.txt. No runtime font-download service is used.

Files total 245,788 bytes before APK compression. Native Material typography roles retain sp units and zero letter spacing. Monospaced protocol evidence remains explicitly monospaced where necessary.
