# ProxyX 7.0.2

فایل نصب: ProxyX-v7.0.2.apk

فایل Android App Bundle: ProxyX-v7.0.2.aab

- نسخهٔ اصلاح‌شده با کد نسخهٔ 72 و همان کلید امضای نسخه‌های قبلی ساخته شده است. فایل APK حدود ۳۴٫۱ مگابایت است.
- APK را به‌صورت به‌روزرسانی روی نسخهٔ قبلی نصب کنید؛ حذف برنامه یا پاک‌کردن داده‌ها برای نصب لازم نیست و نشست تلگرام را از بین می‌برد.
- کنترل لغو تست دستی تلگرام در نوار بالای همهٔ صفحه‌ها قرار دارد و از مرحلهٔ آماده‌سازی تا پایان پاک‌سازی در دسترس می‌ماند.
- پاسخ TCP یا MTProto به‌تنهایی تضمین دانلود فایل نیست. سرعت واقعی فقط پس از انتقال موفق فایل ثبت می‌شود؛ خطاهای واقعی شبکه نباید به‌عنوان سرعت موفق نمایش داده شوند.
- فایل‌های نشست، کلید خصوصی امضا، تنظیمات محلی توسعه‌دهنده و خروجی گنجینهٔ شخصی داخل بسته نیستند.
- TEST-REPORT-fa.md حدود تست و موارد تأییدنشده را توضیح می‌دهد. این بسته تا تکمیل موارد باقی‌مانده، تأیید کامل انتشار عمومی ندارد.
- SHA256SUMS.txt برای کنترل یکسان‌بودن فایل‌ها ارائه می‌شود.
