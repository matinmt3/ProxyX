# ProxyX 5.0.0

این نسخه، مسیر دریافت و ارزیابی پروکسی را از نو روی داده‌های واقعی MTProto متمرکز می‌کند. هیچ سرعت دانلود یا آپلود مصنوعی به پروکسی‌ها نسبت داده نمی‌شود.

## تغییرات اصلی

- دریافت تدریجی پروکسی‌ها از ۵۰ منبع MTProto و جایگزینی کامل کش قبلی در هر Refresh، با حفظ Favoriteهای کاربر و پاک‌کردن نتیجه‌های تست قدیمی.
- کنترل کیفیت منابع شامل آخرین موفقیت، تعداد ورودی منحصربه‌فرد، نرخ سلامت، تشخیص mirror و قرنطینه‌ی خودکار منبع خراب، خالی یا تکراری.
- آزمون سه‌مرحله‌ای واقعی شامل TCP، تأیید MTProto، P90، jitter، پایداری و continuity؛ رتبه‌بندی با Transfer Score و بدون استفاده از عدد نمایشی.
- مرتب‌سازی‌های Best، High، Download/Upload، TCP latency، Telegram latency و Country بر پایه‌ی داده‌های ذخیره‌شده در دیتابیس.
- انتقال واقعی تطبیقی ۰٫۵ تا ۸ مگابایت از Saved Messages با TDLib، فقط برای فینالیست‌های مرحله‌ی آخر و فقط پس از ورود کاربر.
- ماندگاری امن نشست TDLib روی دستگاه و بازیابی خودکار آن پس از بستن یا به‌روزرسانی برنامه.
- ارسال Favorite به Saved Messages در قالب مرتب، همراه لینک اتصال و اطلاعات اندازه‌گیری‌شده.
- گنجینه‌ی Favoriteها، پوشه، برچسب، یادداشت، QR، پروکسی خصوصی، Last Known Good و مقایسه‌ی پروفایل‌ها.
- Import/Export پروفایل با کنترل SHA-256 و خروجی عیب‌یابی بدون شماره، API hash، نشست یا secret.
- فهرست Paging و مرتب‌سازی دیتابیسی برای هزاران پروکسی، نمایش تدریجی نتایج و جلوگیری از توقف رابط.
- اجرای بنچ‌مارک طولانی با User-Initiated Job/Foreground Service، اعلان پیشرفت و کنترل Pause، Resume و Cancel.
- انتخاب خودکار worker با توجه به CPU، رم، دما، باتری و نوع شبکه، همراه حالت اینترنت نامحدود/Wi-Fi.
- Baseline Profile و Startup Profile تازه، رابط فارسی/انگلیسی و بهبود چیدمان و انیمیشن‌ها.
